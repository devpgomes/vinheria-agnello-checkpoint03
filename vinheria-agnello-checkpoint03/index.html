Sistema de controle de estoque de vinhos

Checkpoint 03

Este sistema utiliza objetos e arrays para cadastrar vinhos, listar os produtos, identificar estoques baixos, calcular o estoque total e mostrar os nomes dos vinhos em caixa alta.

Os dados são preenchidos diretamente no código e os resultados são exibidos no console do navegador.

No Chrome ou Edge para Windows, pressione Ctrl + Shift + J para abrir o console e conferir os resultados.
