## Aluno

Pedro Henrique Gomes Rodrigues

## Funcionalidades implementadas

- Array de objetos com nome, tipo, safra e estoque de cada vinho.
- Função para adicionar novos vinhos ao array com push.
- Listagem dos vinhos com forEach.
- Seleção de vinhos com estoque abaixo de 5 com filter.
- Cálculo do estoque total com reduce.
- Criação de uma lista de nomes em caixa alta com map.
- Exibição de todos os resultados no console do navegador.

## Como executar

1. Abra o arquivo index.html no navegador.
2. No Chrome ou Edge para Windows, pressione Ctrl + Shift + J para abrir o console.
3. Confira a lista completa, os vinhos com estoque baixo, o estoque total e os nomes em caixa alta.

Os dados são definidos no arquivo src/js/script.js. O sistema não utiliza prompt, formulários ou manipulação do DOM. Os dados ficam apenas na memória e são reiniciados ao recarregar a página.
